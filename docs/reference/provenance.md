## Scanner changes by topic

All of these change `grammar/src/scanner.c`, compiled into both grammars.

| Topic | Change |
| --- | --- |
| Pipe-table headers | Track nonblank header content and require a pipe in the delimiter row. Record a rejected delimiter row for the rest of its paragraph, serialize that state, and clear it when the paragraph or its container ends. |
| Definitions and containers | Clear the definition-paragraph state when its container closes, so it cannot suppress an unrelated list marker. Probe paragraph interruption before closing unmatched definition containers, and keep the consumed container boundary. |
| Empty nested list markers | Record paragraph interruption across tokens on one line and serialize it. |
| Lists after reference definitions | Return the consumed indentation before a zero-width close token, so the next match does not count it twice. |
