# Explicit HTTP(S) autolinks

The inline tokenizer accepts literal `http://` and `https://` links with a nonempty, validated host prefix, including dotless hosts. URL-internal brackets and emphasis markers remain part of the URL. Recognition runs before emphasis resolution, so `https://ex**ample.ssage` stays one link. The safe first-host-character, final-label underscore, Unicode decoding, CJK punctuation and bounded-domain checks remain active. The `www` and email policies are unchanged.

The existing text-node fallback requires a dotted host and excludes terminal `>` from explicit HTTP(S) links. After validating the host, its cleanup scans the prefix once to count parentheses and trims disjoint terminal punctuation suffixes. The inline matcher retains internal angle punctuation. These paths differ in the reference implementation too. A global `>` stop would break the saved nested-scheme witness by truncating its outer link.

A text-node candidate with its own punctuation boundary remains valid even when the rest of the authored leaf is an invalid host. For example, `https://example.test._a_` retains the link at 0..20 and the emphasis at 21..24. An unfinished host fragment still checks the full authored candidate for invalid underscores. The original saved no-link expectations for 181/completed/39 and 216/completed/20 remain in force.

`tests/fixtures/autolink-boundaries.json` copies 16 independent saved observations from r122. It records original UTF-16 source hashes, raw observation pointers, expected link text, hrefs, ranges and attention ranges. Lone surrogates stay escaped in JSON and survive the source identity check. Expected values come from the saved reference output, never from this parser's result.

The regression tests check exact/ended links for all 16 observations, supported open links, completed attention, the URL-versus-strong witness, and incremental/fresh equality. They also record native open math ownership separately. These narrower green checks do not satisfy strict live acceptance. The unchanged strict diagnostic still reports four seed230 revisions47/48 open URL failures because an unclosed math node owns the suffix, and seed235 revision19 live has an extra emphasis at 35..74. Two existing incomplete-destination ended fixtures now expect a dotless literal link, as independently confirmed with the reference GFM parser. Their pending open-state expectations and baseline identities are unchanged. The live expected links and attention remain unchanged in the fixture. Fixing those other producers requires their own scope.

This patch does not establish resolution of all 415 URL observations. Seed212 live revisions18/19 and the full product qualification remain unverified. Release numbering and downstream consumption belong to the integration owner.
