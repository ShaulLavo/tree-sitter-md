# Internal notes

Working notes, not user documentation. This folder holds approved plans, per-release evidence, change notes with test counts, measurement dumps and the original spike log. Nothing here describes the current behavior of the package. Read `README.md` and `docs/` for that.

An item leaves when it is finished or stale. A finished plan becomes an ADR in `docs/adr/` or gets deleted. Evidence that a public page cites moves its number and reproducing command into that page, and the raw data is deleted. Git history keeps everything that is deleted.
