# C resolver evidence

Rust baseline: source `4214f0c`, independently built before the port. The wasm hashes are in
`size.json`. C is the checked-in `-O3` wasm, also identified by hash.

`rust-N.jsonl` and `c-N.jsonl` are the unchanged `bench/run-all.sh` outputs. Three paired rounds,
three runs per invocation, alternating build order in round two. `summary.json` is generated by
`scripts/summarize.mjs`. Each Chromium file is the unchanged harness's median of five cold
contexts per case; `chromium-summary.json` takes the median of the three rounds.

`c-checks.txt` records the build, focused tests, per-section spec floor, 497 repository documents,
183 recovered chat messages, both complete fuzz counts and the failing negative control. The
native sanitizer check ran successfully between the focused tests and the spec run. A separate
standalone-import test confirms zero wasm imports. `c-spec.md` and `rust-spec.md` retain the
section tables; the corpus text files retain both builds' aggregate counts.

The direct Rust/C differential over all 497 documents produced no differences in normalized
construct lists. No private corpus text is included here. Input provenance and the recovery
hash are in `../../FINDINGS.md`.

The side-module files record the positive shared-memory probe and the negative stock-runtime
export check. The full unresolved side artifact's size is reported separately from the working
standalone artifact, because it needs a rebuilt host to execute.
